**The free edition of [MCP Server for GLPI](https://github.com/OMNICOM-Digital/mcpserver).**

A GLPI plugin that exposes GLPI as an [MCP](https://modelcontextprotocol.io) (Model Context Protocol) server, so AI assistants can work with GLPI conversationally.

Built and maintained by [Omnicom, s.r.o.](https://omnicom.digital), an ITSM/ESM consultancy.

## Status

In development, no release yet. Releases will be published in this repository under [Releases](https://github.com/OMNICOM-Digital/mcpserver-lite/releases), free for everyone.

For the full toolset, the human-in-the-loop write confirmation and support, see [MCP Server for GLPI](https://github.com/OMNICOM-Digital/mcpserver).

## Compatibility

- GLPI 11.0.0 - 11.9.99, on-premise

## Security

Security support is defined per release line: the 1.x line is supported for at least five years from its first release, and every release extends it. Security fixes are free and published here as security releases with an advisory.

To report a vulnerability, see [SECURITY.md](SECURITY.md) or e-mail security@omnicom.digital. Please do not open public issues for security problems.
